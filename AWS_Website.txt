
========

Launch an EC2 instance

Go to AWS Console → EC2 → Launch Instance.

Choose an OS image (Ubuntu 22.04 LTS is common).

Select instance type (e.g., t2.micro → free tier).

Configure key pair (download .pem file).

Configure security group:

Allow SSH (22) for your IP.

Allow HTTP (80) for everyone.

Allow HTTPS (443) for everyone (if you plan SSL).

Launch instance.

3. Transfer your code

Options:

If your code is on GitHub:
Open Git Bash or CMD and run:

git clone https://github.com/username/repo.git
cd repo


If from PythonAnywhere export (ZIP):
Upload file to Windows EC2 using RDP clipboard or S3 bucket, then extract.

4. Create virtual environment & install dependencies

Open PowerShell or CMD:

cd C:\Users\Administrator\myproject
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

5. Run your app

If it’s Flask/FastAPI app:

python app.py
